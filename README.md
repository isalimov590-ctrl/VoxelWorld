# VoxelWorld

**VoxelWorld** - это кроссплатформенная воксельная игра с открытым исходным кодом, разработанная на Godot Engine 4.6. Проект вдохновлен классическими воксельными играми и модпаком *Better Than Adventure*, предлагая обновленные механики, процедурную генерацию мира, мультиплеер и широкие возможности для кастомизации.

Этот репозиторий содержит полный исходный код для:
- **Игры** (клиент для PC/Android)
- **Лаунчера** (управление аккаунтами, модами и обновлениями)
- **Бэкенд-сервера** (аутентификация, профили, друзья)
- **Выделенного сервера** (для мультиплеера)

## Особенности

| Категория | Функция | Описание |
| :--- | :--- | :--- |
| **Геймплей** | Воксельный движок | Оптимизированный движок на основе чанков (16x16x16) с динамической загрузкой и генерацией мешей. |
| | Генерация мира | Процедурный мир с 5 биомами (равнины, леса, пустыни, горы, тундра), пещерами и рудами. |
| | Система сезонов | Динамическая смена дня/ночи и времен года (весна, лето, осень, зима) с влиянием на игровой мир. |
| | Процедурные данжи | Генерация подземных лабиринтов с комнатами, коридорами и сокровищами. |
| **Мультиплеер** | Кроссплатформенность | Игроки с PC и Android могут играть вместе на выделенных серверах. |
| | Выделенный сервер | Полнофункциональный сервер с консольным управлением, конфигурацией и поддержкой плагинов. |
| | Система аккаунтов | Бэкенд на FastAPI для управления пользователями, профилями и статистикой. |
| | Система друзей | Возможность добавлять друзей, отправлять запросы и видеть их статус. |
| **Кастомизация** | Лаунчер | Лаунчер для управления аккаунтом, обновления игры и установки модов. |
| | Система модов | Поддержка модов через Godot Mod Loader, с простым API для моддеров. |
| | Скины персонажей | Запланирована интеграция с Blockbench для создания 3D-моделей персонажей. |

## Архитектура проекта

Проект разделен на три основных компонента:

1.  **Game/**: Основной игровой клиент, созданный на Godot 4.6. Содержит всю игровую логику, рендеринг и механики.
2.  **Launcher/**: Приложение на Godot 4.6, которое служит для аутентификации, обновления игры и управления модами перед запуском.
3.  **Backend/**: Сервер на Python (FastAPI) с базой данных PostgreSQL, который обрабатывает аккаунты, профили и социальные функции.

```
/VoxelWorld
├── Game/              # Игровой клиент (Godot)
│   ├── core/          # Основная логика (игрок, воксели, системы)
│   ├── multiplayer/   # Сетевая логика
│   ├── server/        # Логика и скрипты выделенного сервера
│   ├── scenes/        # Игровые сцены
│   └── project.godot
├── Launcher/          # Лаунчер (Godot)
│   ├── scenes/        # Сцены UI
│   ├── scripts/       # Скрипты (менеджеры аккаунтов, модов, обновлений)
│   └── project.godot
├── Backend/           # Бэкенд-сервер (FastAPI)
│   ├── models/        # Модели базы данных (SQLAlchemy)
│   ├── routes/        # API эндпоинты
│   ├── main.py        # Главный файл сервера
│   └── requirements.txt
└── README.md          # Этот файл
```

## Установка и запуск

Для полного развертывания проекта требуется настройка всех трех компонентов. Подробные инструкции находятся в README каждого компонента.

### 1. Бэкенд-сервер

Сначала необходимо запустить бэкенд, так как он требуется для работы лаунчера.

- **Требования**: Python 3.11+, PostgreSQL 14+.
- **Инструкции**: `cd Backend && pip install -r requirements.txt && python main.py`
- **Подробнее**: [Backend/README.md](Backend/README.md)

### 2. Лаунчер

Лаунчер используется для входа в аккаунт и запуска игры.

- **Требования**: Godot Engine 4.6.
- **Инструкции**: Откройте проект `Launcher/` в Godot и запустите его.
- **Подробнее**: [Launcher/README.md](Launcher/README.md)

### 3. Игра

Игра запускается через лаунчер. Для разработки можно запустить напрямую.

- **Требования**: Godot Engine 4.6.
- **Инструкции**: Откройте проект `Game/` в Godot и запустите сцену `main.tscn`.
- **Подробнее**: [Game/README.md](Game/README.md)

### 4. Выделенный сервер

Для мультиплеера необходимо запустить выделенный сервер.

- **Требования**: Godot Engine 4.6 (headless build).
- **Инструкции**: `cd Game/server && ./server_launcher.sh`
- **Подробнее**: [Game/server/README.md](Game/server/README.md)
