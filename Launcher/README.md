# VoxelWorld Launcher

Официальный лаунчер для VoxelWorld с управлением модами и аккаунтами.

## Возможности

- **Управление аккаунтами** - Вход, регистрация, профиль
- **Менеджер модов** - Установка, удаление, включение/отключение модов
- **Автообновление** - Автоматическая проверка и установка обновлений
- **Запуск игры** - Удобный запуск игры с настройками

## Сборка

### Требования

- Godot Engine 4.6
- Доступ к интернету (для аутентификации и обновлений)

### Инструкции

1. Откройте проект в Godot Engine 4.6

2. Экспортируйте для нужной платформы:
   - Project -> Export
   - Выберите платформу (Windows, Linux, macOS)
   - Настройте параметры экспорта
   - Нажмите "Export Project"

## Использование

### Первый запуск

1. Запустите лаунчер
2. Войдите в аккаунт или зарегистрируйтесь
3. Дождитесь загрузки игры (если не установлена)
4. Нажмите "Play"

### Управление модами

1. Нажмите "Mods" в главном меню
2. Установите моды из файла или по URL
3. Включите/отключите нужные моды
4. Моды автоматически копируются в игру при запуске

### Настройки

В настройках можно изменить:
- Путь установки игры
- API URL бэкенда
- Параметры запуска игры
- Настройки обновлений

## Структура

```
Launcher/
├── project.godot        # Конфигурация проекта
├── scenes/              # Сцены UI

│   └── main_menu.gd
└── scripts/             # Скрипты
    ├── account_manager.gd
    ├── mod_manager.gd
    ├── game_updater.gd
    └── config.gd
```

## API

Лаунчер взаимодействует с бэкенд сервером для:
- Аутентификации пользователей
- Синхронизации профилей
- Получения списка модов
- Проверки обновлений

API URL по умолчанию: `http://localhost:8000`

## Разработка

### Добавление новых функций

1. Создайте новую сцену в `scenes/`
2. Добавьте скрипт в `scripts/`
3. Подключите к главному меню

### Тестирование

Для тестирования без бэкенда:
1. Закомментируйте проверку авторизации
2. Установите `play_button.disabled = false`
