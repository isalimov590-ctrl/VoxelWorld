# VoxelWorld

VoxelWorld - это кроссплатформенная воксельная игра, вдохновленная модпаком Better Than Adventure для Minecraft Beta 1.7.3. Игра разработана на Godot Engine 4.6 и включает обновленные механики, систему данжей, мультиплеер и кастомизацию персонажей.

## Особенности

### Геймплей
- **Система сезонов** - Весна, Лето, Осень и Зима с уникальными эффектами
- **Процедурные данжи** - Лабиринты с редкой добычей и опасными мобами
- **Прогрессия инструментов** - От дерева до стали (эндгейм материал)
- **Гибкая система брони** - Комбинируйте части брони для разных эффектов
- **Разнообразные биомы** - Равнины, леса, пустыни, горы и многое другое

### Мультиплеер
- **Кроссплатформенность** - Играйте с друзьями на PC, Android и других платформах
- **Выделенные серверы** - Простой инструмент для создания серверов
- **Система друзей** - Добавляйте друзей и играйте вместе

### Кастомизация
- **Система скинов** - Создавайте уникальные скины персонажей
- **Интеграция Blockbench** - Импортируйте модели из Blockbench
- **Достижения** - Уникальные достижения за выполнение задач

### Моды
- **Godot Mod Loader** - Встроенная поддержка модов
- **API для моддеров** - Простой API для создания модов
- **Лаунчер с менеджером модов** - Управляйте модами через лаунчер

## Технологии

- **Движок**: Godot Engine 4.6
- **Язык**: GDScript
- **Воксели**: Godot Voxel Tools
- **Сеть**: ENet (UDP с надежностью)
- **Бэкенд**: Python FastAPI + PostgreSQL
- **Платформы**: PC (Windows/Linux/macOS), Android
